# Changelog

## 1.0.0 — 2026-10-03

- Package the installer as an Editor-only Unity Package Manager package.
- Install thirteen Git packages and DOTween through individual buttons.
- Pin Git dependencies to verified tags or commits and check installation prerequisites.
- Support URP PostProcessing Toolkit 2.0.0 alongside the shared Event Bus.
- Provide a scrollable installer window and DOTween setup shortcut.
